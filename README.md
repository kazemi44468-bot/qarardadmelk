# گروه تعاون ملک ایرانیان | مبایعه‌نامه پیش‌فروش آپارتمان

فرم فارسی و راست‌چین برای آماده‌سازی پیش‌نویس مبایعه‌نامه پیش‌فروش آپارتمان، با امکان تکمیل در مرورگر و چاپ یا ذخیره به PDF. تنظیم‌کننده و ارائه‌دهنده این قالب: **گروه تعاون ملک ایرانیان**.

## انتشار در GitHub Pages
این سایت استاتیک است و نیازی به build ندارد. مخزن به workflow انتشار خودکار در GitHub Actions مجهز شده است. در مخزن به مسیر **Settings → Pages → Build and deployment → Source** بروید و **GitHub Actions** را انتخاب کنید؛ سپس در زبانه Actions اجرای workflow را بررسی کنید. پس از موفقیت انتشار، آدرس سایت:
https://kazemi44468-bot.github.io/qarardadmelk/

## فایل‌ها
- `index.html` — فرم کامل قرارداد و مشخصات طرفین و ملک.
- `assets/css/style.css` — طراحی واکنش‌گرا و نسخه چاپ A4؛ فونت‌ها فقط از فایل‌های محلی مخزن بارگیری می‌شوند.
- `assets/js/app.js` — ردیف‌های پرداخت، جمع مبالغ، راهنما و چاپ.
- `assets/images/logo.png` — لوگوی گروه تعاون ملک ایرانیان.
- `404.html` — صفحه خطای مسیر ناموجود با لینک بازگشت به قرارداد.

اطلاعات واردشده در فرم در مرورگر باقی می‌ماند و به سرور ارسال یا به‌صورت خودکار ذخیره نمی‌شود.

## ملاحظه حقوقی
این قالب پیش‌نویس عمومی است و تضمین‌کننده اعتبار معامله یا سازگاری با وضعیت ثبتی هر ملک نیست. پیش‌فروش ساختمان در ایران تابع الزامات قانونی و ثبتی ویژه است؛ چاپ صفحه به‌تنهایی جایگزین تنظیم و ثبت رسمی الزامی نمی‌شود. پیش از استفاده واقعی، متن و مدارک را با وکیل یا دفتر اسناد رسمی آشنا با مقررات روز بررسی کنید.
